# 楠梓高中 AI 商店物件偵測與結帳系統

## 📋 概述

這是一個基於 YOLO 的圖形化物品偵測應用程式，專門為楠梓高中商店設計。系統能夠即時辨識商品、計算總價，並提供友善的使用者介面進行結帳。

採用 **Tkinter** 構建視覺化介面，整合 **YOLO26** 物件偵測模型，支援攝影機即時偵測和圖片批量偵測。

---

## ✨ 功能特性

- 🎥 **即時攝影機偵測** - 透過網路攝影機即時辨識商品
- 🖼️ **圖片偵測** - 載入圖片檔案進行物品偵測
- 🛒 **自動結帳** - 即時計算偵測商品的總價
- 📊 **結果清單** - 以表格形式顯示偵測商品、信心度和價格
- ⚙️ **配置彈性** - 透過 `config.json` 自訂模型、商品名稱和價格
- 💾 **標註保存** - 自動保存標註結果圖片

---

## 🔧 系統需求

### 依賴套件
- Python 3.9+
- tkinter（通常內建 Python）
- OpenCV (`cv2`)
- Pillow (`PIL`)
- Ultralytics YOLO (`ultralytics`)

### 必要檔案
- `ui_app.py` - 主應用程式
- `bestn.pt` 或 `bestm.pt` - 訓練好的 YOLO 模型（根據 config.json 設定）
- `config.json` - 設定檔（包含模型路徑、類別名稱、價格表）
- `msjh.ttc` - 繁體中文字型檔案

---

## 📦 安裝步驟

### 1. 安裝依賴

```bash
pip install opencv-python pillow ultralytics
```

### 2. 準備模型和配置

確保工作目錄內包含以下檔案：

```
├── ui_app.py           # 主程式
├── config.json         # 設定檔
├── bestm.pt            # YOLO 模型（在 config.json 中指定）
├── msjh.ttc            # 中文字型
└── nths_s.png          # 學校 Logo（選用）
```

### 3. 配置 config.json

```json
{
  "model": "bestm.pt",
  "confidence_threshold": 0.5,
  "class_names": {
    "0": "商品名1",
    "1": "商品名2"
  },
  "price_map": {
    "商品名1": 35,
    "商品名2": 40
  }
}
```

---

## 🚀 使用方法

### 啟動應用程式

```bash
python ui_app.py
```

### 操作步驟

1. **啟動攝影機** - 點擊「📷 啟動攝影機」按鈕自動開啟即時偵測
2. **載入圖片** - 點擊「📁 載入圖片並偵測」選擇圖片檔案
3. **查看結果** - 左側顯示影像和邊界框，右側清單顯示偵測結果
4. **檢查總價** - 「總計」區域自動計算所有偵測商品的價格
5. **停止攝影機** - 點擊「🛑 停止攝影機」關閉即時偵測

---

## ⚙️ 配置說明

### config.json 參數

| 參數 | 說明 | 預設值 |
|------|------|--------|
| `model` | YOLO 模型檔案名稱 | `bestn.pt` |
| `confidence_threshold` | 偵測信心度閾值（0-1） | `0.5` |
| `class_names` | 商品類別名稱對應表 | - |
| `price_map` | 商品名稱與價格對應表 | - |

### 自訂商品

在 `config.json` 的 `class_names` 和 `price_map` 中新增或修改商品資訊：

```json
"class_names": {
  "0": "巧克力",
  "1": "洋芋片"
},
"price_map": {
  "巧克力": 35,
  "洋芋片": 55
}
```

## 📸 介面說明

### 左側 - 影像顯示區
- 顯示即時攝影機畫面或載入的圖片

## 🔍 除錯與常見問題

### 無法開啟攝影機
- 檢查攝影機是否被其他應用程式佔用
- 嘗試修改 `config.json` 中的 `camera.device_id`（預設為 0）

### 模型載入失敗
- 確認 `config.json` 中的 `model` 檔案名稱正確
- 檢查模型檔案是否存在於工作目錄

### 中文字型顯示異常
- 確認 `msjh.ttc` 檔案存在
- 更新 `ui_app.py` 中的字型設定

### 偵測結果不準確
- 調整 `config.json` 的 `confidence_threshold`（降低值以提高靈敏度）
- 確保光線充足
- 驗證 YOLO 模型是否正確訓練

## 📝 程式碼架構

**`ProductDetector`** - YOLO 物品偵測器
- 整合 YOLOv8 模型推論

- 管理 Tkinter UI 介面
- 控制攝影機即時擷取
- 處理圖片載入和偵測
- 更新結帳清單和總價
